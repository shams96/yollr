✅ Phone number → Auto-create account → Immediate feed access → Progressive profiling ✅ TTF <30 seconds ✅ Profile completion after first interaction ✅ Friend invites auto-connect

Current: Buttons → Login page → OTP New: Phone input DIRECTLY on landing page

├─ Phone input field (prominent)
├─ "Continue" button
├─ Auto-detect location for campus suggestion
├─ "Or join via friend invite" link
└─ Skip login entirely - just phone number

Flow:

Click "Continue"
Immediately create account + session (passwordless)
Show feed instantly with demo campus data

Benefits:
No waiting for OTP
Instant gratification
Can verify phone later if needed
